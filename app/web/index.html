操作与连线说明

节点：左侧「常用节点」8 个够用；低频的固件操作在底部「高级节点」。拖入画布或双击添加，空白处右键也能加。

连线：只有金色执行流（决定执行顺序）。 ① 按住金色方块端口拖到目标节点；② 或先点一下起点端口，再点一下目标端口。 蓝色数据连线已移除 —— 断言写在节点内部（如 I²C 行的「期待值」）。旧画布里残留的蓝线仍会保留执行。

删连线：单击连线选中（高亮），按 Delete 删除 —— 不再点一下就删。 删节点：选中后按 Delete。误操作 Ctrl+Z 撤销。

参数编辑：右侧属性面板。I²C 节点是表格，顶部统一 Slave ID，下面逐条指令，每条指令各自指定类型（读 / 读并校验 / 写 / 写并回读校验）和位宽(a2d4 等)， 「期待值」留空就不断言，填了就做回读值比对（⚙ 里还能设遮罩与右移）；每行都能拖拽排序、存为常用寄存器预设。 Device 出图检查是操作列表：只拖左侧 ⠿ 换顺序，参数跟在操作后面一行。

伸缩布局：下方运行台的上边缘可上下拖拽调整高度，右侧属性台的左边缘可左右拖拽调整宽度（双击边缘复位，尺寸会记住）。

本 case 独立空间：一个画布 = 一个 case。下方运行台分三栏 —— 运行日志 / 图片 / 历史，都是这个 case 自己的产物，放在 logs/cases/<case>/。 「🗑 清空本 case ▾」可一键清掉它的日志、图片或全部，不影响别的 case。

调试：选中节点后点「⤵ 运行到此」—— 会把它依赖的上游节点先跑一遍再停在这里，设备保持上电/已配置状态。

平移/缩放：空白处拖动 = 平移；滚轮 = 以鼠标为中心缩放；右下角 ＋/－/⛶。

自动保存：改动后 1.5 秒自动落盘，顶栏 ● 表示尚未保存到最后一次操作。
