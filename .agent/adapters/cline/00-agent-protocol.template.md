# Agent Protocol (template)

This is the bundled reference for Cline workspace rules generated by `co adapt cline`.

Project output path: `.clinerules/00-agent-protocol.md`

The generated file delegates to root `AGENTS.md` (which Cline also loads) and only
adds Cline-specific MCP setup. Session entry, hard rules, and protocol-map live in
`AGENTS.md`. `co adapt cline` also writes `.agents/skills/`.

See also: `adapters/cline/readme.template.md`, `adapters/cline/mcp-snippet.template.json`.
